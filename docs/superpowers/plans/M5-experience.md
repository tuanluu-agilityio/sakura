# M5 Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Read `docs/superpowers/plans/README.md` (constraints, contract, layout) first. Steps use `- [ ]`.

**Goal:** The complete visitor experience: pastel loading screen, a cinematic intro with a train passing, a Start button, a translucent minimal UI with menu/i18n, photo mode with share/download, and graceful fallbacks.
**Architecture:** Three features (`intro`, `ui`, `photo`) that talk only through the bus and `ctx.mode`; shared `src/shared/i18n.ts`; core gets two small additions (`src/core/fallback.ts` WebGL guard, `src/core/frame-hooks.ts` render hooks). DOM overlays are plain HTML/CSS (no framework) above the canvas, `pointer-events: none` on containers and `auto` on controls.
**Tech Stack:** TypeScript, DOM, CSS; Playwright for e2e.
**Spec:** `docs/superpowers/specs/2026-11-07-sakura-relax-design.md` §2.1, §2.4–§2.6, §3.5, §9.

## Global Constraints
See README "Global constraints". Additionally for M5: UI text only through `t(key)` (no literal user-facing strings in feature code); touch targets ≥ 44×44 px; UI font `system-ui`, weight 300 (400 for buttons), light translucent panels (`rgba(255,255,255,0.72)`, `backdrop-filter: blur(8px)`, radius 14 px, text `#4a3b47`); every interactive element is a real `<button>`/`<input>` with `aria-label`; DOM built with `createElement`/`textContent` (no `innerHTML` with dynamic data); CSS in `src/style.css` or a feature-local `.css` imported by the feature. **Start gate:** M5-T1, T3 and T4 use `t()`; M5-T2 step 1 (`i18n.ts` + test) is committed and merged as its own tiny PR first, then T1/T3/T4 may start. `ctx.setMode` assumptions (documented in M3): the player/camera features only act while `ctx.mode === 'play'`; in every other mode they leave `ctx.camera` alone.

## Review Focus
1. Double-tap / double-click on Start → mode changes once, tween runs once (test in T1: `startOnce`).
2. Esc pressed while a photo is being captured → ignored; mode restored to the pre-photo mode exactly once (test in T3: `canStartPhoto`/`finishPhoto`).
3. Language switched while the menu is open → all visible labels update, focus stays on the toggle (test in T2: e2e `language switch keeps focus`).
4. WebGL context lost during the intro → loop paused, fallback appears after 3 s, resumes if restored later (test in T4: `createContextWatcher`).
5. Download blocked / unsupported on iOS Safari → Web Share path with a `File`, `AbortError` treated as cancel, other errors fall back to download (test in T3: `deliver`).

### Task M5-T3: Photo mode
**Model:** sonnet · **Type:** ui · **Size:** S · **Depends:** M5-T0
**Files:** Create `src/core/frame-hooks.ts`, `src/features/photo/{index.ts,capture.ts,signature.ts,deliver.ts,filename.ts,README.md}`, tests `src/features/photo/{filename,deliver,flow}.test.ts`, `tests/e2e/photo.spec.ts`; Modify `src/main.ts` (use frame hooks), `src/features/index.ts`.
**Interfaces:**
- `frame-hooks.ts` (core): `export const frameHooks = { pixelRatioOverride: null as number | null, afterRender: new Set<() => void>(), resize: () => {} }`. `main.ts`: sets `frameHooks.resize` to its resize function, resize uses `frameHooks.pixelRatioOverride ?? Math.min(devicePixelRatio, ctx.quality.maxPixelRatio)`, and calls every `afterRender` callback immediately after the frame is rendered (composer included) in the same tick.
- Photo: `photoFilename(d: Date): string` → `sakura-YYYYMMDD-HHmmss.png` (local time); `canStartPhoto(mode: GameMode, busy: boolean): boolean` (true only for `'play'` and not busy); `chooseDelivery(env: { canShareFiles: boolean; touch: boolean }): 'share' | 'download'` (share only if both true); `deliver(blob, name, env: { share?: (d: ShareData) => Promise<void>; canShare?: (d: ShareData) => boolean; touch: boolean; download: (blob, name) => void }): Promise<'shared' | 'downloaded' | 'cancelled'>` — `AbortError` → `'cancelled'`, any other share error → download; `download` creates an `<a download>` with `URL.createObjectURL`, revokes after 10 s. `drawSignature(g: CanvasRenderingContext2D, w: number, h: number): void` — text "sakura" bottom-right, font `300 ${h*0.025}px system-ui`, fill `rgba(255,255,255,0.85)`, margin `h*0.03`, soft shadow.
- Flow (`index.ts`): on `'photo:request'` or `consumeAction('photo')`: if `canStartPhoto(ctx.mode, busy)` → `busy=true; prev=ctx.mode; setMode('photo'); bus.emit('ui:visibility',{visible:false})`; set `frameHooks.pixelRatioOverride = Math.min(2, devicePixelRatio)` and `frameHooks.resize()`; wait 2 rendered frames via an `afterRender` callback counter; on the third, copy `renderer.domElement` into an offscreen canvas with `drawImage`, `drawSignature`, `canvas.toBlob(..., 'image/png')`; then restore (`pixelRatioOverride = null`, `resize()`, `setMode(prev)` only if `ctx.mode === 'photo'`, `ui:visibility` true), show the 150 ms white flash `<div id="flash">` (opacity 0→0.9→0), `deliver(...)`, emit `'photo:done', { blob }`, `busy=false`. The shutter sound is played by the audio feature on `'photo:request'` (do not import audio). While `ctx.mode === 'photo'`, `menu` action is ignored by the ui feature (Review 2); pressing Esc has no effect. A 5 s watchdog restores state if `toBlob` never calls back.
- [ ] Tests first: `photoFilename(new Date(2026, 10, 7, 14, 5, 9)) === 'sakura-20261107-140509.png'`; `canStartPhoto('menu', false)===false`, `('photo', false)===false`, `('play', true)===false`, `('play', false)===true`; `deliver` with `share` rejecting `new DOMException('x','AbortError')` → `'cancelled'` and `download` not called; rejecting `Error` → `'downloaded'`; `touch:false` → `'downloaded'` without calling share; `chooseDelivery({canShareFiles:true,touch:false})==='download'`. `flow.test.ts`: simulate sequence with fakes — request while busy ignored (one `photo:done`), mode restored to `'play'` exactly once.
- [ ] e2e: `test('P key downloads a png')` — enter play, `Promise.all([page.waitForEvent('download'), page.keyboard.press('p')])`, filename matches `/^sakura-\d{8}-\d{6}\.png$/`, `__sakura.mode === 'play'` afterwards, `#hud` not hidden by the photo after 1 s.
