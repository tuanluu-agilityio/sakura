# M4 Audio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Read `docs/superpowers/plans/README.md` (constraints, contract, layout) first. Steps use `- [ ]`.

**Goal:** A calm soundscape: generative or sourced piano/koto music, wind, stream, birds, positional train + crossing bell, footsteps, shutter — all working with zero audio files (procedural fallback) and upgraded by dropping files into a manifest.
**Architecture:** One feature `src/features/audio/` (engine + procedural synth + wiring). Every sound has an `id`; `manifest.ts` maps id → files | `'procedural'`; the engine resolves id → `AudioSource` (file-backed or procedural) and never throws. Train position comes from the pure shared module `src/shared/train-schedule.ts` (created in M2-T2; features cannot import features, so audio reads the schedule from `shared`).
**Tech Stack:** Web Audio API through `THREE.AudioListener`; no audio libraries.
**Spec:** `docs/superpowers/specs/2026-11-07-sakura-relax-design.md` §3.4, §7.

## Global Constraints
See README "Global constraints". Additionally for M4: each audio file ≤ 200 lines; no `setInterval`/`setTimeout` for game logic (use `update(dt)` accumulators so a hidden tab produces no event burst); all random choices take an injectable `rng: () => number` (default `Math.random`) so tests are deterministic; max 24 simultaneously playing sources; `AudioContext` is created lazily by `THREE.AudioListener` and only resumed after a user gesture.

## Review Focus
1. Game starts before file buffers are decoded → `create()` must resolve with the procedural source after `LOAD_TIMEOUT_MS = 3000`, never hang (test in T1).
2. iOS `AudioContext` state `'interrupted'` after a phone call / Siri → engine retries `resume()` on the next user gesture (test in T1).
3. Settings change while muted (slider moved, then unmute) → bus gains already hold the new volumes, master is the only thing muted (test in T1).
4. Tab hidden for an hour, then visible → no queued bird/horn/step burst; horn only fires when the train crossed its trigger point within the last 50 m of travel (test in T4).
5. Safari / iOS has no `.ogg` → `pickFormat` returns the `.m4a` URL (test in T1).

### Task M4-T1: Audio engine, buses, source registry, manifest
**Model:** sonnet · **Type:** audio · **Size:** M · **Depends:** none
**Files:** Create `src/features/audio/{index.ts,engine.ts,gains.ts,registry.ts,manifest.ts,types.ts,test-utils.ts,README.md}`, tests `src/features/audio/{gains,registry,engine}.test.ts`; Modify `src/features/index.ts` (append `audio`).
**Interfaces:**
- Consumes: `ctx.camera`, `ctx.settings`, `ctx.bus`, `ctx.assets.audio(url)`, `ctx.input.consumeAction('mute')`.
- Produces (`types.ts`):
  ```ts
  type SourceKind = 'music' | 'ambient' | 'sfx';
  interface AudioSource { readonly duration: number; readonly procedural: boolean;
    setPosition(x: number, y: number, z: number): void;   // no-op unless created with positional
    start(o?: { loop?: boolean; rate?: number; gain?: number }): void;
    stop(fadeSec?: number): void; setParam(name: string, v: number): void; onEnded?: () => void; }
  type SourceFactory = (env: { ctx: AudioContext; out: AudioNode; rng: () => number }) => AudioSource;
  type ManifestEntry = 'procedural' | { ogg: string; m4a: string };
  interface AudioEngine { readonly listener: THREE.AudioListener; readonly state: AudioContextState;
    registerSource(id: string, kind: SourceKind, factory: SourceFactory): void;
    create(id: string, o?: { positional?: { refDistance: number; maxDistance?: number; rolloff?: number } }): Promise<AudioSource>;  // never rejects
    ensureRunning(): Promise<void>; dispose(): void; }
  ```
- `gains.ts`: `computeGains(s: Settings): { master: number; music: number; ambient: number; sfx: number }` — master = `s.muted ? 0 : 1`; music = clamp01(`musicVolume`); ambient = sfx = clamp01(`ambientVolume`); NaN/undefined → defaults 0.4 / 0.6.
- `manifest.ts`: `export const MANIFEST: Record<string, ManifestEntry>` with ids `music-01 music-02 music-03 wind birds stream train-run train-horn crossing-bell step-grass step-dirt step-wood step-stone shutter`, ALL `'procedural'` initially (T3 fills). `pickFormat(entry: ManifestEntry, canPlay: (mime: string) => CanPlayTypeResult): string | null` → `null` for `'procedural'`; `.ogg` url if `canPlay('audio/ogg; codecs="vorbis"') !== ''` else `.m4a` url.
- `registry.ts`: `createRegistry()` → `{ register(id, kind, factory); get(id): { kind; factory } | undefined }`; duplicate id overwrites (last wins).
- Debug: `window.__sakuraAudio = { state, gains(): {master,music,ambient,sfx}, voices(): number }` (separate global; used by e2e).
- [ ] Tests first (`test-utils.ts` provides `fakeAudioContext()` with controllable `state`, recorded GainNode params, `statechange` dispatch, and a fake `assets.audio`): `computeGains({muted:true, musicVolume:0.4, ambientVolume:0.6,...})` → master 0, music 0.4, ambient 0.6 (Review 3); `computeGains({musicVolume: NaN as any,...}).music === 0.4`; `pickFormat({ogg:'a.ogg',m4a:'a.m4a'}, () => '') === 'a.m4a'` and with `() => 'probably'` → `'a.ogg'` (Review 5); `pickFormat('procedural', …) === null`.
- [ ] Engine tests (fake timers): `create('wind')` with manifest file + `assets.audio` resolving → `procedural === false`; `assets.audio` rejecting → `procedural === true`, promise resolves; `assets.audio` never resolving → resolves procedural after 3000 ms (Review 1); unknown id → resolves a silent no-op source (all methods safe); fake context state `'interrupted'` + `ensureRunning()` registers a one-shot `pointerdown`/`touchend` listener that calls `resume()` (Review 2); `'game:mode'` → `play` first time calls `resume()` exactly once more not at all later; `visibilitychange` hidden → `suspend()`, visible → `resume()` only if it had been started.
- [ ] Implement `engine.ts`: `new THREE.AudioListener()` added to `ctx.camera`; three `GainNode` buses (music, ambient, sfx) connected to `listener.getInput()`; master via `listener.setMasterVolume`. Apply `computeGains` at init (immediate) and on every `'settings:change'` with a 0.3 s ramp: `cancelScheduledValues(now); setValueAtTime(current, now); linearRampToValueAtTime(target, now + 0.3)`. Resume triggers: first `'game:mode'` with `mode === 'play'`, plus a first `pointerdown`/`keydown` fallback (removed after the first successful resume; harmless once M5 start button exists). `update()` calls `ctx.input.consumeAction('mute')` → `ctx.settings.set({ muted: !ctx.settings.get().muted })`. Positional sources: engine inserts a `PannerNode` (`distanceModel: 'inverse'`, `panningModel: 'equalpower'`) between source gain and bus; position via `positionX.value` if defined else `setPosition`.
- [ ] `create(id)`: look up manifest entry → `pickFormat(entry, new Audio().canPlayType.bind(...))` → `ctx.assets.audio(url)` raced against 3000 ms → wrap buffer in an `AudioBufferSourceNode`-based `AudioSource` (new node per `start`); any failure → registered procedural factory for that id; none registered → silent no-op source. Log one `console.warn('[audio] fallback', id)` per id, never throw.
- [ ] `index.ts`: feature `{ name: 'audio', init, update, dispose }`; `init` builds engine, installs `window.__sakuraAudio`; leave two comment hooks `// M4-T2: registerProcedural(engine)` and `// M4-T4: wireAudio(ctx, engine)` (those tasks add one line each). `README.md` ≤ 20 lines.

### Task M4-T2: Procedural fallback synth
**Model:** sonnet · **Type:** audio · **Size:** M · **Depends:** M4-T1
**Files:** Create `src/features/audio/procedural/{index.ts,noise.ts,wind.ts,stream.ts,birds.ts,bell.ts,steps.ts,train.ts,music.ts,pluck.ts,reverb.ts,shutter.ts}`, tests `src/features/audio/procedural/{music,pluck,birds,reverb,bell}.test.ts`; Modify `src/features/audio/index.ts` (one line).
**Interfaces:**
- Consumes: `registerSource`, `SourceFactory`, `AudioSource` (T1 `types.ts`).
- Produces: `registerProcedural(engine: AudioEngine): void` registering a factory for **every** manifest id: `wind`, `stream`, `birds` (one chirp per `start()`), `crossing-bell`, `train-run`, `train-horn`, `step-grass|dirt|wood|stone`, `shutter`, `music-01|02|03`.
- Pure helpers (all unit-tested, no Web Audio): `scaleFreq(scale: 'minorPent' | 'in', degree: number, rootHz = 293.66): number` (D4 root; minorPent semitones `[0,3,5,7,10]`, in `[0,1,5,7,8]`, degree wraps octaves, negative degrees allowed); `nextMusicEvent(state, rng): { dt: number; degree: number | null }` (beat = 60/66 s; 45 % chance of a note per beat, random walk ±1–2 degrees clamped to −5..+9, 1 in 8 chance of two-note chord degree+2); `chirpParams(rng): { startHz: number; endHz: number; durMs: number; fmDepth: number }` (startHz 2500–4500, endHz ±40 %, durMs 60–180); `birdGapSeconds(rng): number` ∈ [4, 15]; `bellPartials(): { hz: number; gain: number; decay: number }[]` (two tones 700 and 850 Hz, each with partials ×1, ×2.76, ×5.4); `impulseResponse(len: number, decay: number, rng): Float32Array` (exponentially decaying noise, first sample ≈ ±1, last |x| < 0.01).
- Behaviour: `wind` = looped pink-noise buffer (2 s, shared `noise.ts`) → lowpass (400–1200 Hz) → gain; `setParam('gust', v 0..1)` sets gain `0.15 + 0.85 v` and filter freq `400 + 800 v` with 0.2 s smoothing. `stream` = noise → bandpass 900 Hz Q 0.8 + second bandpass 2400 Hz at 0.3 gain, slow LFO 0.3 Hz on gain ±10 %. `birds` = sine oscillator with FM (`fmDepth`) and pitch sweep per `chirpParams`, 2–4 chirps per `start()` 120 ms apart; `birdGapSeconds` is exported for wiring. `crossing-bell` = two alternating strikes (700/850 Hz) every 0.5 s (2 Hz) while started (scheduled with `ctx.currentTime` look-ahead in `setParam`-free `start()` using a 25 ms-tick-free approach: pre-render one 1 s `AudioBuffer` of two strikes and loop it). `train-run` = brown noise lowpass 180 Hz + 4 Hz amplitude pulse (wheel clack) ; `train-horn` = two detuned sawtooth (311 / 392 Hz) lowpass 1200 Hz, 1.6 s with attack 0.15 s / release 0.5 s. `steps`: 120 ms noise bursts — grass bandpass 2000 Hz Q 0.5 (soft), dirt lowpass 900 Hz, wood bandpass 600 Hz Q 4 + 100 Hz thump, stone highpass 1500 Hz with fast 40 ms decay; `rate` option shifts filter freq. `shutter` = two 25 ms noise clicks 60 ms apart through bandpass 3000 Hz.
- Music: `pluck.ts` `renderPluck(ctx, hz, seconds = 3, rng): AudioBuffer` — Karplus-Strong (delay-line length `sampleRate/hz`, averaging damping 0.996, lowpass-ish) computed in a JS loop **on demand and cached by rounded Hz** (no AudioWorklet; cap cache at 24 entries, LRU). `music.ts` source: each tick (driven by a `ctx.currentTime` scheduler advanced from a `requestAnimationFrame`-free lookahead of 0.5 s — use a single `setTimeout` chain created ONLY inside this source while started, cleared on `stop`) plays plucks via `nextMusicEvent`, velocity gain 0.15–0.35, routed through a `ConvolverNode` (`reverb.ts`: `impulseResponse(sampleRate * 2.5, 3.2, rng)`, wet 0.35). Tracks differ by (`scale`, `rootHz`, `rng seed`): `music-01` minorPent D, `music-02` `in` D, `music-03` minorPent A (220 Hz). `duration` = 120 s; `onEnded` fires after 120 s of started time (counted from `ctx.currentTime`).
- [ ] Tests first: `scaleFreq('minorPent', 0) ≈ 293.66`, `(…, 5) ≈ 587.33` (octave), `(…, -1) ≈ 220` (C→A? compute: degree −1 = A3 = 220 Hz, assert within 0.5); `scaleFreq('in', 1) ≈ 311.13`; with seeded rng (mulberry32(1)) 2000 calls to `nextMusicEvent`: note ratio within 0.35–0.55, degrees within −5..9, mean `dt` ≈ 0.909 ± 0.01; `chirpParams` 500 samples all in ranges; `birdGapSeconds` 500 samples within [4,15]; `bellPartials()` contains 700 and 850 first-partials and all `decay > 0`; `impulseResponse` first/last-sample bounds; `renderPluck` with fake context (`createBuffer` stub) returns buffer whose peak ≤ 1 and RMS of last 10 % < 5 % of first 10 % (decays).
- [ ] Implement; keep CPU light: no per-sample JS in the audio thread (all synthesis via native nodes or pre-rendered buffers); `renderPluck` of one note ≤ 15 ms (log timing under `?debug=1`).
- [ ] Add `registerProcedural(engine)` line to `audio/index.ts`; manually listen with `npm run dev` and confirm each id plays: add dev-only `window.__sakuraAudio.play(id)` (only when `?debug=1`) for this.
**Acceptance:** typecheck; unit tests green; build; with every manifest entry `'procedural'` and `?debug=1`, `__sakuraAudio.play('wind')` etc. create sources without console errors (e2e `test('procedural sources construct for every manifest id')` iterating `Object.keys(MANIFEST)` via a debug hook); screenshot not required.

### Task M4-T4: Wiring and spatial audio
**Model:** sonnet · **Type:** audio · **Size:** M · **Depends:** M4-T1, M4-T2
**Files:** Create `src/features/audio/{wiring.ts,train-audio.ts,ambient.ts,steps.ts,music-player.ts,geometry.ts}`, tests `src/features/audio/{train-audio,ambient,steps,music-player,geometry}.test.ts`; Modify `src/features/audio/index.ts`. Do NOT touch `src/shared/train-schedule.ts` (M2-T2 owns it; it already applies `LAYOUT.train.startOffset`).
**Interfaces:**
- Consumes: `trainStateAt(t: number): { active: boolean; direction: 1 | -1; frontX: number; run: number }` from `src/shared/train-schedule.ts`; `ctx.time.elapsed`; `LAYOUT.crossing` (x,z), `LAYOUT.trees` (`{x,z,scale}[]`), `LAYOUT.mainTree`, the stream polyline in `LAYOUT.stream` (read `layout.ts` for the exact field); bus events `crossing:state`, `player:step`, `photo:request`; `ctx.wind`, `ctx.player.position`.
- Produces: `wireAudio(ctx: WorldContext, engine: AudioEngine): { update(dt: number): void; dispose(): void }`; pure helpers `trainEmitter(s, carLen = 18, cars = 3): { x: number; z: number; audible: boolean }` (x = `frontX - direction * carLen * cars / 2`, z = `LAYOUT.crossing.z`, audible = `active`); `hornTrigger(run: number, rng): number` (distance before the crossing, 120–200 m, seeded by `mulberry32(run)`); `shouldHorn(prevFront, front, direction, crossingX, trigger): boolean` (true iff the front passes the point `crossingX - direction*trigger` between the two samples AND `|front - prevFront| < 50`); `windGain(gust, strength): number` = `0.2 + 0.6*gust + 0.2*min(1, strength)`; `emittersAround(poly, x, z, spacing = 10): {x,z}[]` (3 points: nearest polyline point to (x,z) and ±spacing along arclength); `birdSpot(trees, px, pz, rng): {x,y,z} | null` (random tree within 40 m of player, y = 6·scale; null if none); `createStepLimiter(max = 4, minGapSec = 0.12)`; `createPlaylist(ids, rng): { next(): string }` (never repeats the previous id).
- [ ] **Step 0 (verify only):** open `src/shared/train-schedule.ts`; confirm `trainStateAt(t)` returns `{ active, direction, frontX, run }`. If a field name differs, adapt the audio code to the real names (do not edit the shared module). Pass `ctx.time.elapsed` as `t`.
- [ ] Tests first: `trainEmitter({active:true,direction:1,frontX:100,run:0})` → x 73; `direction -1` frontX 100 → x 127; inactive → `audible false`; `hornTrigger(3, …)` deterministic and within [120,200]; **`shouldHorn(80, 82, 1, 10, 150)`** → `false` (front crosses −140? compute: trigger point = 10−150 = −140; false) and `shouldHorn(-141, -139, 1, 10, 150)` → true; `shouldHorn(-300, 500, 1, 10, 150)` → false (jump > 50 m, tab-hidden case, Review 4); `windGain(0,0) === 0.2`, `windGain(1,1) === 1`; `emittersAround` on a straight polyline `(0,0)→(100,0)` at player `(50,5)` → x `[40,50,60]`, y/z 0; near polyline end clamps to endpoints; `createPlaylist(['a','b','c'], rng)` 200 draws never equal consecutive; `createStepLimiter` rejects 5th concurrent and a step <0.12 s after previous; `birdSpot([], …) === null`.
- [ ] Implement `wiring.ts`: 
  - Train: one `train-run` source (kind sfx, positional refDistance 20, maxDistance 400, rolloff 1.2, loop) started when `active` becomes true, stopped (0.8 s fade) when false; each frame `setPosition(trainEmitter(...))`; horn: once per `run` via `shouldHorn` + `train-horn` positional at the front position, gain 0.7.
  - Crossing bell: on `'crossing:state'` `closed:true` start looped `crossing-bell` positional at `LAYOUT.crossing`, refDistance 8, rolloff 1.5; `closed:false` stop with 0.3 s fade.
  - Stream: three looped `stream` positional sources (refDistance 6) repositioned every frame via `emittersAround(streamPoly, player.x, player.z)`; gain 0 when player farther than 60 m from any point (skip the update to save CPU).
  - Wind: one looped `wind` ambient (non-positional); each frame `setParam('gust', windGain(...))`-style call: `wind.setParam('gust', ctx.wind.gust)` and engine ambient level untouched (user volume stays on the bus).
  - Birds: accumulator `nextBird = birdGapSeconds(rng)` decremented by `dt` (clamped by the core to 0.1); on zero create one `birds` positional source at `birdSpot`, refDistance 4, then `start()`; re-arm.
  - Footsteps: on `'player:step'` unless `surface === 'water'`: `createStepLimiter` check, `create('step-'+surface)` (cache sources per surface), `start({ rate: 0.9 + rng()*0.2, gain: running ? 1 : 0.7 })`.
  - Shutter: on `'photo:request'` create `shutter` once (cached) and `start()` (sfx bus).
  - Music: `music-player.ts` plays `music-01` first, then `createPlaylist` order; when the current source `duration - 4` seconds of play time elapsed (counted with `dt`, not wall-clock) crossfade 4 s into the next (old `stop(4)`, new `start()` with fade-in 4 s by gain ramp); after a track ends insert a random silence gap of 20–40 s (`MUSIC_GAP = [20, 40]`); lazily `create()` the next track at the crossfade start.
  - `dispose()` stops everything and unsubscribes.
- [ ] Hook `wireAudio` into `audio/index.ts` (replace the `M4-T4` comment) and call `wiring.update(dt)` from the feature's `update`.
**Acceptance:** typecheck; all unit tests green; no file under `src/features/audio` imports from another feature (`git grep "features/" src/features/audio` shows only own-folder paths); build; e2e `test('audio wiring runs a full train cycle without errors')` (advance 90 s of game time is impractical → use `?debug=1` hook `__sakuraAudio.voices()` and assert it is ≥ 1 within 20 s of entering play at the default intro train offset, and no console errors); update `src/features/audio/README.md`.
