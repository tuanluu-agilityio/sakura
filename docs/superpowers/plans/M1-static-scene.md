# M1 Static Scene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Read `docs/superpowers/plans/README.md` (constraints, contract, layout) first. Steps use `- [ ]`.

**Goal:** Standing still at the spawn/intro pose looks beautiful: toon-lit sakura grove on a mound, drifting petals, Fuji and soft sky, with character assets ready for later milestones.
**Architecture:** One feature folder per concern (`postfx`, `sky`, `fuji`, `terrain`, `sakura-trees`, `petals`), each exporting `default` a `Feature` and registered by appending to `src/features/index.ts` in this order: `sky, postfx, fuji, terrain, sakura-trees, petals`. Cross-feature data flows only through `ctx` (`terrain`, `colliders`, `wind`, `bus`, `quality`) and `LAYOUT`. `src/shared/toon.ts` and `src/shared/characters.ts` are shared modules (not features).
**Tech Stack:** three (M0 pin), GLSL via `?raw`, `three/examples/jsm` (EffectComposer, GLTFLoader), `@gltf-transform/cli` (npx, assets only).
**Spec:** `docs/superpowers/specs/2026-11-07-sakura-relax-design.md` §2–§3, §9.3 (T7 only).

## Global Constraints
See README "Global constraints". Additionally for M1: all colours come from `PALETTE` (no hex literals outside `palette.ts`, except inside tests); no per-frame allocations in `update`; every feature implements `dispose()` (geometries, materials, textures, bus unsubscribes, colliders removed) and `setQuality`; visual tasks attach an e2e screenshot (`tests/e2e/<feature>.spec.ts`, camera at `LAYOUT.intro` start pose, saved to `test-results/<feature>-<project>.png`) to the PR and state which palette entries are visible in it.

## Review Focus
1. Petals popping in/out at the wrap boundary → T6 test `petal wrap is invisible`: the vertex-shader fade factor is 0 at both y extremes and at the spawn-volume lateral edge (pure TS mirror `petalFade(t, lateral)` unit-tested).
2. Shadow acne / peter-panning on toon terrain (tilted mound, thin trunks) → T2 sets `shadow.bias = -0.0004`, `normalBias = 0.04`; e2e in T4 asserts via `?debug=1` screenshot no striping on the mound (manual check line in PR) and unit test pins the constants exported from `src/features/sky/light.ts`.
3. Grass rebuild leak on repeated `setQuality` → T4 test `grass setQuality x20 does not leak`: after 20 level switches `renderer.info.memory.geometries` equals the count after the first switch and the old `InstancedMesh` is removed from the scene.
4. Character `.glb` missing a clip (or differently named) → crash on `play()` → T7 test `clip-name mapping`: `resolveClip(names, 'sit')` falls back to `idle` then first clip and never throws on a clip list that lacks `sit`; e2e asserts all four clips exist for all three characters.
5. Fog swallowing Fuji at low `viewDistance` (220 m vs Fuji at 900 m) → T1/T3 test `fog never hides fuji`: `fogRange(viewDistance)` keeps fog `far` ≥ 2000 for sky/Fuji via a separate `fogExempt` uniform in the Fuji material; T3 e2e samples centre-of-Fuji pixel at `low` and requires it differs from the horizon colour by ΔE-ish RGB distance > 12.
